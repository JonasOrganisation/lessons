```html Mémo terminal

Mémo - Commandes Terminal

Raccourcis essentiels et exemples pratiques

Actions

Action Commande
Savoir où je suis pwd
Lister les fichiers ls
Lister avec détails ls -l
Voir les fichiers cachés ls -a
Détails + fichiers cachés ls -la
Entrer dans un dossier cd dossier
Revenir au dossier parent cd ..
Revenir au dossier personnel cd ~
Aller à la racine cd /
Créer un dossier mkdir dossier
Créer plusieurs dossiers mkdir dossier1 dossier2
Créer une arborescence mkdir -p dossier/sous-dossier
Créer un fichier touch fichier.txt
Copier un fichier cp fichier.txt copie.txt
Copier un dossier cp -r dossier copie-dossier
Déplacer un fichier mv fichier.txt dossier/
Renommer un fichier mv ancien.txt nouveau.txt
Supprimer un fichier rm fichier.txt
Lire un fichier cat fichier.txt
Lire progressivement less fichier.txt
Rechercher dans un fichier grep "texte" fichier.txt
Recherche sans casse grep -i "texte" fichier.txt
Recherche récursive grep -r "texte" dossier/
Enchaîner des commandes commande1 && commande2
Filtrer la sortie d’une commande commande | grep "texte"
Nettoyer le Terminal clear
Voir l’historique history
Arrêter une commande Ctrl + C
Nettoyer l’écran Ctrl + L
Commande précédente ↑
Commande suivante ↓
⚠ Supprimer un dossier - ATTENTION rm -r dossier

⚠ rm -r supprime un dossier et tout son contenu sans passer par la corbeille.

Exemples

# Voir où je suis
pwd

# Voir tous les fichiers
ls -la

# Aller dans un projet
cd mon-projet

# Revenir au dossier précédent
cd ..

# Créer un projet
mkdir mon-projet

# Créer une arborescence
mkdir -p mon-projet/assets/images

# Créer plusieurs fichiers
touch index.html style.css script.js

# Copier un fichier
cp index.html index-copy.html

# Copier un dossier
cp -r assets assets-copy

# Déplacer un fichier
mv style.css assets/

# Renommer un fichier
mv script.js main.js

# Supprimer un fichier
rm index-copy.html

# Lire un fichier
cat index.html

# Rechercher un mot dans un fichier
grep "header" index.html

# Rechercher sans tenir compte des majuscules/minuscules
grep -i "header" index.html

# Rechercher dans tous les fichiers d’un dossier
grep -r "background" assets/

# Enchaîner plusieurs commandes
cd mon-projet && ls

# Créer un dossier puis entrer dedans
mkdir nouveau-projet && cd nouveau-projet

# Installer puis lancer le projet
npm install && npm run dev

# Rechercher dans le résultat d’une commande
ls -la | grep ".js"

# Rechercher un processus
ps aux | grep node

# Nettoyer le Terminal
clear

# DANGER : supprimer un dossier et tout son contenu
rm -r assets-copy
```
