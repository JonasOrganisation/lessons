Mémo Git — Commandes essentielles

Avec les commandes d’annulation, reset, revert, amend et checkout.

Actions

Initialisation et état

Commande Description
git init Initialiser un dépôt.
git clone <url> Cloner un dépôt distant.
git status Voir l’état du dépôt.
git log --oneline Voir l’historique compact.
git log --oneline --decorate --graph --all Voir l’historique graphique.

Branches

Commande Description
git branch Lister les branches locales.
git branch -a Lister branches locales et distantes.
git branch -vv Voir les branches suivies.
git switch main Changer de branche.
git switch -c feature/xxx Créer une branche et basculer dessus.
git branch -m nouveau-nom Renommer la branche courante.
git branch -d branche Supprimer une branche locale fusionnée.

Modifications et commits

Commande Description
git diff Voir les modifications non indexées.
git diff --staged Voir ce qui sera commité.
git add fichier Ajouter un fichier au staging.
git add -A Ajouter toutes les modifications.
git commit -m "Message" Créer un commit.
git restore --staged fichier Retirer un fichier du staging sans perdre ses modifications.

Annuler ou corriger des modifications

Commande Effet Usage
git restore fichier Annule les modifications locales non indexées. Revenir au dernier état Git d’un fichier.
git checkout -- fichier Ancienne syntaxe pour annuler les modifications locales d’un fichier. Ancien équivalent de git restore fichier.
git reset HEAD fichier Retire un fichier du staging, conserve les modifications locales. Ancienne manière de “unstage”.
git reset --soft HEAD~1 Annule le dernier commit mais garde les modifications dans le staging. Refaire immédiatement le dernier commit.
git reset HEAD~1 Annule le dernier commit et garde les modifications hors staging. Retravailler les fichiers avant de recommitter.
git reset --hard HEAD~1 Annule le dernier commit et supprime aussi les modifications locales. À utiliser seulement si tu veux jeter les changements.
git revert <SHA> Crée un nouveau commit qui annule les effets d’un ancien commit. Recommandé pour annuler un commit déjà poussé sur GitHub/GitLab.
git commit --amend -m "Nouveau message" Modifie le message du dernier commit. Corriger un message avant le push.
git add fichier
git commit --amend 		Ajoute un fichier oublié au dernier commit. À faire surtout avant le push.
git checkout <SHA> Se placer temporairement sur un ancien commit. Consulter/tester une ancienne version. Retour : git switch main.
Règle simple :

Modification locale à annuler → git restore

Dernier commit local à corriger → git commit --amend ou git reset

Commit déjà poussé à annuler → git revert

Voir un ancien commit → git checkout <SHA>
Attention : git reset --hard peut supprimer des modifications locales. Évite-le si tu n’es pas certain de vouloir les perdre.

Dépôt distant

Commande Description
git remote -v Voir les dépôts distants.
git fetch origin Récupérer les nouveautés sans modifier les fichiers locaux.
git pull Récupérer et intégrer les nouveautés.
git push Envoyer les commits.
git push -u origin branche Premier push d’une branche + suivi distant.
git push origin --delete branche Supprimer une branche distante.

Fusion et conflits

Commande Description
git merge origin/main Fusionner origin/main dans la branche courante.
git status Voir les fichiers en conflit.
git add fichier Marquer un conflit comme résolu.
git commit Terminer le merge.
git merge --abort Annuler un merge en cours.

GitHub Flow

  1. git switch main
  2. git pull
  3. git switch -c feature/ma-feature
  4. Modifier les fichiers
  5. git status
  6. git diff
  7. git add -A
  8. git diff --staged
  9. git commit -m "Description claire"
  10. git push -u origin feature/ma-feature
  11. Créer la Pull Request
  12. Fusionner la Pull Request
  13. git switch main
  14. git pull
  15. git branch -d feature/ma-feature
  16. git push origin --delete feature/ma-feature

Raccourcis Git Bash

Raccourci Effet
Ctrl + C Annuler la commande en cours.
Ctrl + U Effacer la ligne en cours.
Ctrl + L Nettoyer l’écran.
↑ Rappeler la commande précédente.
